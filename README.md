An interactive dashboard was created to analyze sales trends, customer segments, and product size distribution. 
Key findings showed that supermarkets achieved the highest sales and that 500 ml to 1.5 l packs performed best. 
Discount and distribution cost analyses supported pricing and logistics optimization. 
The dashboard enabled managers to prioritize channels, plan promotions, and increase profitability. 
Furthermore, detailed product-level insights provided many other insights.
